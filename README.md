# Cognitive Fingerprint

## Download

| Your computer | Download | Then |
|---|---|---|
| **Mac** (Apple silicon or Intel) | [**Download for Mac**](https://github.com/Fun-Stuff-Shared/cognitive-fingerprint/releases/latest/download/Cognitive-Fingerprint-Mac.dmg) | Open the file and drag Cognitive Fingerprint into Applications. Open it from Applications. |
| **Windows** (10 or 11) | [**Download for Windows**](https://github.com/Fun-Stuff-Shared/cognitive-fingerprint/releases/latest/download/Cognitive-Fingerprint-Windows.exe) | Open the file. If Windows asks, press More info, then Run anyway. |

Both links always give you the newest version. After that, the app keeps itself up to date.

## Set up

1. Open the app. Setup starts on its own.
2. **Claude Code:** setup checks that Claude Code is installed and signed in, then one button connects it to the app.
3. **Sign in:** choose Sign in with email and type the 6-digit code we email you, or paste the key you were given.
4. Setup walks you through the rest, about five minutes.
